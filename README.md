# Calcora.us – Online Calculator Suite

Calcora.us is a comprehensive platform featuring **80+ online calculators** built with **Next.js** and **Tailwind CSS**.  
Designed to be fully responsive, fast, and optimized for **SEO**, this project provides a wide range of calculators for finance, math, general, and daily utility purposes.

##  Features
- **80+ calculators** for finance, math, general, and daily tasks
- Built as a **Single Page Application (SPA)** for fast performance
- **Fully responsive** design using Tailwind CSS
- **SEO optimized** using Next.js for better search engine visibility
- Clean and modern UI/UX
- Easy to extend with new calculators
